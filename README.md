# Специальный выпуск — автономная версия

## Исправление

В предыдущей версии карточки редакционной планёрки подгружались из отдельного
`config.js`. При открытии только `index.html` браузер мог не получить соседний
файл, поэтому планёрка оставалась пустой.

В этой версии все тексты, карточки и демонстрационная статистика встроены прямо
в HTML. Основной файл полностью автономен.

## Открытие

- `index.html` — основной автономный сайт;
- `special_edition_standalone.html` — его дополнительная копия;
- `analyzer.html` — анализ Telegram JSON.

## Тема

Журналистика стала оформляющей темой:

1. закрытый спецвыпуск;
2. аккредитация корреспондента;
3. редакционная планёрка;
4. экстренный эфир «Победа над психозиком»;
5. делулу-фактчек;
6. исследовательский отдел со статистикой смеха;
7. редакционный архив;
8. авторская колонка манюни.

Леопардовая шуба остаётся одной внутренней шуткой, а не общей темой сайта.


## Новый этап

Добавлена игра «Резюме Шуры Муравской». В резюме нужно по очереди добавить:

- харизму;
- красоту;
- сексуальность;
- трудолюбие;
- умение работать даже во время психозика;
- статус главной самки.

После выбора материала переход больше не происходит автоматически:
появляется отдельная кнопка, поэтому ответ редакции можно спокойно прочитать.
